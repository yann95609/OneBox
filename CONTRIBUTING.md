# Directives de Contribution à ONEBOX

Merci pour votre intérêt envers ONEBOX ! Ce projet open source vise à fournir un espace personnel local-first pour capturer et organiser ses informations en toute confidentialité.

## Principes de Contribution

1. **Local-first prioritaire** : Aucune fonctionnalité centrale ne doit dépendre d'un service cloud tiers obligatoire.
2. **Confidentialité** : Les données privées de l'utilisateur ne doivent jamais être transmises sans consentement explicite.
3. **Tests obligatoires** : Tout nouveau cas d'usage ou correction de bug doit s'accompagner de tests dans le dossier `test/`.
4. **Validation des modifications** :
   ```bash
   npm test
   ```
